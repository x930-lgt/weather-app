# 天気情報アプリ

## 概要

TypeScriptで作成した天気情報アプリです。

都市名を入力すると、Open-Meteo APIから位置情報と現在の天気情報を取得し、画面に表示します。

## 使用技術

* HTML
* CSS
* TypeScript
* Vite
* Vitest

## API

- Open-Meteo API

## 機能

* 都市名から位置情報を検索
* 現在の天気情報を取得
* 天気・気温・風速の表示
* 天気コードに応じた天気名とアイコンの表示
* 検索中・取得完了・エラー状態の表示
* Enterキーによる検索
* 都市名未入力時のエラー表示
* 存在しない都市名を入力した場合のエラー表示

## 工夫した点

* `async / await` を使用してAPI通信の非同期処理を実装しました。
* 都市の位置情報取得と天気情報取得の処理を `weatherApi.ts` に分離しました。
* TypeScriptの型を活用し、APIから取得した位置情報や天気情報のデータ構造を定義しました。
* 天気コードに応じた天気名とアイコンに変換する処理を実装しました。
* 検索中は検索ボタンを無効化し、処理状態が分かるようにしました。
* API通信に失敗した場合や都市が見つからない場合など、エラー内容に応じてメッセージを表示するようにしました。
* API通信処理に対してVitestを使用した単体テストを実施しました。
* 実際のAPI通信を模擬するため、テストでは`fetch`をモックしてテストを実施しました。

## 単体テスト

Vitestを使用して、API通信処理の単体テストを実施しています。

### `getCoordinates`

* 都市名から緯度・経度を取得できること
* 存在しない都市名の場合にエラーになること

### `getWeather`

* 緯度・経度から天気情報を取得できること
* 天気情報の取得に失敗した場合にエラーになること

以下のコマンドでテストを実行できます。

```bash
npm run test
```

## 起動方法

### 1. リポジトリをクローン

ターミナルで以下のコマンドを実行してください。

```bash
git clone https://github.com/x930-lgt/weather-app.git
cd weather-app
```

### 2. 依存パッケージをインストール

以下のコマンドを実行してください。

```bash
npm install
```

### 3. 開発サーバーを起動

以下のコマンドを実行してください。

```bash
npm run dev
```

起動後、ターミナルに表示されたURLをブラウザで開いてください。
